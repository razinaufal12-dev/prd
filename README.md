# PlanAI

PlanAI is an AI Product Planner landing page and product-flow prototype based on the PlanAI MVP plan.

## Flow

- Landing page
- Sign up / login
- Dashboard
- Create New Project
- Describe Your Idea
- AI Interview
- AI Analysis
- Generate Product Plan
- Project Workspace
- Create Development Tasks
- AI Coding Prompt
- Export / Copy / Continue Editing

## Local preview

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## GitHub Pages

This project is configured for GitHub Pages with static export.

1. Push this repository to GitHub.
2. Open the repository on GitHub.
3. Go to Settings -> Pages.
4. Set Build and deployment source to GitHub Actions.
5. Push to `main` or run the "Deploy to GitHub Pages" workflow manually.

The free GitHub Pages URL will be:

```text
https://YOUR_USERNAME.github.io/YOUR_REPOSITORY_NAME/
```

If the repository is named `YOUR_USERNAME.github.io`, the free URL will be:

```text
https://YOUR_USERNAME.github.io/
```
